# F5B A科目计时器

原生 Android 计时应用，提供 F5B A 科目比赛预设和可保存的自定义分段计时方案。

## 获取和安装

- 安装包：[`release/F5B-A-Timer-v1.6.apk`](release/F5B-A-Timer-v1.6.apk)
- 将 APK 下载或传到 Android 手机，在文件管理器中打开，并按系统提示允许安装。
- 最低支持 Android 6.0（API 23）。中文播报依赖手机系统的中文 TTS 语音数据。

## 自定义方案

在主界面切换到“自定义”并打开“方案设置”。先设置整场总时长（秒），例如 5 分钟填 `300`；再添加分段并设置每段时长、正计时或倒计时、报时间隔。所有分段时长合计必须刚好等于总时长。例如 300 秒可分为 10 秒、50 秒和 240 秒三段。方案可命名保存，之后可从“载入已保存方案”切换；也可新建空白方案。还可单独启用总时长结束后的超时计时，设置超时上限、报时间隔和计时方向；超时段不计入分段总时长。

计时大屏始终显示整场累计时间，经过分段边界时不会归零。分段仅决定对应时段采用哪种报时规则：正计时按整场已用时间的间隔倍数触发，倒计时按整场剩余时间的间隔倍数触发；报点不从分段起点重新计数。报时间隔小于 10 秒时，语音只读数字以缩短播报；每段间隔均可按秒设置，填 `1` 即逐秒报时。整场结束时播报“时间到”；若开启超时计时，大屏继续累计显示并按独立设置的规则播报。改动方案后计时器会重置。

F5B 预设规则、计时精度和播报时序见[技术说明](docs/TECHNICAL.md)。

## 从源码构建

使用 Android Studio 打开项目并同步 Gradle，或在已安装 JDK 17 和 Android SDK 35 的环境中执行：

```powershell
.\gradlew.bat assembleDebug
```

构建使用 Android Gradle Plugin 8.7.3 和 Gradle 8.9。默认 `assembleDebug` 生成的 APK 使用 Android 默认 debug 签名，适合侧载和分享测试；发布到应用商店前应配置个人 release 签名密钥。
