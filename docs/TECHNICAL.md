# F5B A 科目计时器技术说明

版本：1.2
应用 ID：`com.f5b.timer`  
最低 Android 版本：Android 6.0（API 23）  
构建工具：Android Gradle Plugin 8.7.3、Gradle 8.9、JDK 17

## 1. 功能组成

应用使用原生 Android `Activity` 和系统 `TextToSpeech`，没有引入第三方运行时库。主界面提供模式切换、方案设置、大字时间、阶段提示及开始/暂停/继续/重置控制。

- **F5B A 科目预设**：按固定比赛时间表播报；超过 5 分钟后继续正读加时。
- **自定义分段方案**：按列表顺序连续执行多个计时段；每段可编辑名称、时长、正计时/倒计时方向及报时间隔。
- **本地保存**：方案通过应用私有 `SharedPreferences` 以 JSON 保存，退出后再次打开仍保留。
- **屏幕常亮**：计时页面使用 `FLAG_KEEP_SCREEN_ON`，减少比赛过程屏幕熄灭的可能。

## 2. 自定义分段行为

每段时长在单个输入框中直接按秒输入，范围为 1 秒至 24 小时。例如 10 秒时长填 `10`，不需要换算成分钟和秒。报时间隔也按秒输入且必须大于 0。列表支持添加、编辑、删除和上移/下移。方案总时长等于所有分段时长之和，保存配置后计时重置。

- 正计时段从该段 `00:00` 开始显示；播报值是该段已过时间。
- 倒计时段从该段设定时长开始显示；播报值是该段剩余时间。
- 当该段已运行秒数大于 0，且为播报间隔的整数倍时播报一次。间隔设为 `1` 即逐秒报时。
- 分段按列表顺序立即衔接，不插入额外间隔。切换时显示下一段的初始值；中间段结束时不额外播报“0”。最后一段结束时显示 `00:00`、播报“时间到”并停止。
- 自定义方案按整套方案剩余时间显示提示色：剩余超过 60 秒为绿色，60 秒内为黄色，30 秒内为红色，完成后保持红色。
- 编辑并保存方案会重置当前计时，避免把旧方案的进度误用于新方案。

例：添加 3 分钟正计时（每 30 秒播报）和 2 分钟倒计时（每 5 秒播报），整套方案共 5 分钟；第二段从 `02:00` 开始显示，播报 `01:55`、`01:50` 等。

## 3. F5B 预设报时表

| 比赛时间 | 播报 |
| --- | --- |
| 1–10 秒 | 逐秒正读 |
| 30 秒–3 分 30 秒 | 每 30 秒播报一次 |
| 4:00 | “4分钟” |
| 4:05–4:25 | 报距 5:00 的剩余秒数：55、50、45、40、35 秒 |
| 4:30–4:55 | 落地倒计时：30、25、20、15、10、5 秒 |
| 5:00 | “时间到” |
| 超过 5:00 | 每秒正读加时；红底闪烁 |

4:00 起界面变黄，4:30 起变红，超时后红底闪烁。超时时钟显示比赛总用时，阶段提示另外显示加时时长。

## 4. 计时精度与播报

应用不通过“刷新次数”累计时间，而是每次刷新按单调时钟重新计算：

```text
已用时间 = 暂停前累计毫秒 +（当前 elapsedRealtime - 本次开始时刻）
```

界面每 100 毫秒检查一次时钟并显示到秒；这个刷新周期只影响界面更新和报点请求提交，不会累积成计时误差。暂停时立即保存已用毫秒数；继续时记录新的开始时刻，因此暂停间隔不计入。

Android [`TextToSpeech.speak()`](https://developer.android.com/reference/android/speech/tts/TextToSpeech#speak(java.lang.CharSequence,int,android.os.Bundle,java.lang.String)) 是异步调用，应用使用 `QUEUE_FLUSH` 以新报点替换本应用尚未播放的旧报点，避免滞后播报排队。系统主线程若被长时间阻塞，时间显示仍会按单调时钟校准，但可能漏掉错过的单个报点；应用不会事后补播过期报点。语音启动时间还受系统调度和手机 TTS 引擎影响。

用户在播报中按暂停，计时立即冻结；已开始的语音可能继续播完，但计时不会等语音结束后自动恢复，须由用户再次按“继续”。计时基准采用 Android [`SystemClock.elapsedRealtime()`](https://developer.android.com/reference/android/os/SystemClock#elapsedRealtime())。

## 5. 构建和签名

```powershell
.\gradlew.bat assembleDebug
```

需安装 JDK 17 和 Android SDK Platform 35。构建结果位于 `app/build/outputs/apk/debug/app-debug.apk`；仓库交付目录包含已编译的 `release/F5B-A-Timer-v1.2.apk`。该安装包使用 Android 默认 debug 签名，可直接侧载和分享；它不是用于 Google Play 发布的 release 签名包。

应用不请求网络、定位、存储等运行时权限。中文语音依赖手机系统 TTS 引擎及其中文语音数据。
